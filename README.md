# quilt-atlas

**The living map of the SuperInstance account.** One scheduled workflow re-inventories every repo every 6 hours: families, motion, CI coverage on the moving frontier — and commits the diff. The map only grows truer; nothing is deleted.

## Why an atlas

The account crossed 300 repos and multiple agent lanes push daily. No single lane can hold the whole graph in its head anymore — and per the stone standard, a *stranger* should be able to see what this fleet is and whether it's alive. The atlas is that stranger's first receipt: counts, families, motion, and CI coverage, regenerated by the same account it describes.

## Families (v2: name-first, then description — precedence: jev > latent > moth > qthe > quilt > fleet)

- **jev** — the JEV living-model arc (jev-garden, jeviter, jev-quilt, quilt-jev-toolkit)
- **latent** — JEPA / latent-grid worlds (quilt-jepa, elephant)
- **moth** — quantum substrate (MicroMoth-quilt, moth-research, quantum-audio-honesty)
- **qthe** — 8-bit ternary hyper-embeddings + canon (qthe, qthe-codec, canon-*)
- **quilt** — the canvas and its games/tools (quilt, quilt-cloudflare, quilt-arcade, quilt-tools)
- **fleet** — the organs (fleet-seeds, crab-traps, si-fleet)
- **other** — honest residue, not failure

**v2 (53-e):** a repo whose *name* matches nothing gets a second chance via its *description* — case-insensitive substring scoring against a small synonym table per family (e.g. quilt: "reactive cell", "cell runtime", "sheet"; jev: "living model", "jepa"; fleet: "agent", "lane", "receipt"), highest score wins, ties broken by family precedence. Every repo records its evidence — `[family, stage, matched keywords, language]` — in `atlas.json` → `classification`, so every assignment is auditable. Still imperfect on purpose; now the imperfection shows its work.

Honesty laws: families are name-then-description classified (imperfect on purpose, stated in atlas.json notes); CI is probed only on the top-motion slice — absence elsewhere is **UNMEASURED**, never reported as zero.

## Usage

```bash
GITHUB_TOKEN=... node scripts/build_atlas.mjs   # regenerates atlas.json + README block
```

Or let the schedule do it: `atlas.yml` runs every 6h and on demand.
